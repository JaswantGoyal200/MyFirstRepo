## Lab Manual number 7

Github Introduction

### Sequence of commands in command prompt
cd Desktop [Navigating to the folder where we want to store the repository: cd is for current directory] <br>
git clone https://github.com/your-username/MyFirstRepo.git [Clone the repository: Git will download the repository into a new folder named MyFirstRepo] <br>
cd MyFirstRepo [Enter into this repository folder]

verify the repository: <br>
dir [check the files] <br>
git status [check the git status] <br>
git remote -v  [check the remote github URL]

Extra:
git pull origin main [update the existing local repository with remote changes]
git add README.md[Staging tells Git which changes you want to include in the next commit]
