## Lab Manual number 7

Github Introduction

### Sequence of commands in command prompt
cd Desktop [Navigating to the folder where we want to store the repository: cd is for current directory] <br>
git clone https://github.com/your-username/MyFirstRepo.git [Clone the repository: Git will download the repository into a new folder named MyFirstRepo] <br>
cd MyFirstRepo [Enter into this repository folder]

verify the repository: <br>
dir [check the files] <br>
git status [check the git status] <br>
git remote -v  [check the remote github URL]

Extra:
git push origin main [uploads local commits, refers to github remote repository into the main destination branch] <br>
git pull origin main [update the existing local repository with remote changes] <br>
git add README.md[Staging tells Git which changes you want to include in the next commit] <br>
git commit -m "Add README file" [commit saves a snapshot of your staged changes in your local Git repository.] <br>
git push origin main [upload your commit to the remote GitHub repository's main branch.]
