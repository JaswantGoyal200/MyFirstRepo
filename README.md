## Lab Manual number 7

Github Introduction

### Sequence of commands in command prompt
cd Desktop [Navigating to the folder where we want to store the repository: cd is for current directory]
git clone https://github.com/your-username/MyFirstRepo.git [Clone the repository: Git will download the repository into a new folder named MyFirstRepo]
cd MyFirstRepo [Enter into this repository folder]

verify the repository: 
dir [check the files]
git status [check the git status]
git remote -v  [check the remote github URL]

Extra:
git pull origin main [update the existing local repository with remote changes]
